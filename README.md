# Calculator lab kit

Starter files of the CI/CD and QoS lab. Follow the lab handout.

- services/: five Node.js microservices (code, unit tests, Dockerfile)
- k8s/: Kubernetes manifests
- scripts/: helpers to build the images by hand
- tools/: patch file used in Part 5
- .github/workflows/cicd.yml: the pipeline you complete in Part 3
